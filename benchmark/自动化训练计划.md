# JEPA 自动化学习训练计划（知识累积制）

> 目标：快速提升模型智商。诊断表明学习策略机制（落点 1-5：受阻触发/受阻-通过沉淀/可证伪性/认知再生产指标/软校准/检索区分度）已验证到当前架构天花板，**剩余提升空间全在知识侧**。本计划解决知识侧两大瓶颈：①知识零累积（训练成果随 body 销毁）②资料库覆盖不足。

---

## 一、诊断结论（2026-08-24 深夜测试数据）

| 瓶颈 | 现状 | 证据 |
|---|---|---|
| **知识零累积**（最大） | learner_loop 每科创建干净 body，训练完即弃，responder 内化的知识全部丢失 | 连跑 5 次不同开关组合均稳定 22.9-24%，分数不随轮次上升 |
| **资料库覆盖不足** | 资料库 171 条（每科 12-36 条）vs 测试题每科 100 道 | econometrics 类题查证 0 覆盖；global_facts 仅 12/25 覆盖 |
| **学习动作有效性** | 查证命中相关知识的题才有学习增量 | 实验 A 方法论教训：触发策略收益只在"学习动作有效"前提显现 |
| 同构混叠 | 已由词汇一致性双条件闸缓解 | 混叠 52→44，答对含金量 ~89% |

**推论**：模型不缺学习策略，缺的是"学过的东西留得住、教材够用"。"快速提升智商"的杠杆 = **知识持久化 + 教材扩充 + 自动化循环**。

## 二、训练计划架构（三层）

```
┌─────────────────────────────────────────────────────┐
│ L2 质量反馈: 评估轮(考试) + 分数曲线 + 收敛判定      │
│   评估 12 题/科 (与训练题不重叠) → 查证学习 → 答题   │
├─────────────────────────────────────────────────────┤
│ L1 训练执行: auto_train.py 循环                     │
│   训练轮 24 题/科 → 查证学习 → 答题 → 判定          │
├─────────────────────────────────────────────────────┤
│ L0 知识供给: 经验回放入库 (知识单调累积)             │
│   答对 → (问题|正确选项) 写回资料库, 下轮直接用      │
│   答错 → 绝不入库 (受阻-通过判据: 实践考验通过才沉淀)│
└─────────────────────────────────────────────────────┘
```

### L0 知识供给——教材采集 + 经验回放（两层互补）

- **教材采集**（auto_train 训练轮，主通道）：训练题以 `问题全文 | 正确选项` 直接入库——**教材正确性由数据标注（choices[ans] = ground truth）保证，与模型是否答对无关**。训练/评估解耦，知识积累不受模型瓶颈限制。等价于 MMLU train 集的本地版（test 集劈半：一半当教材，一半当考试）。
- **经验回放**（模型自积累，次通道）：模型答题**答对**的知识写回资料库——受阻-通过判据的持久层兑现（"被实践考验且通过才沉淀"，命题 1+3）。答错绝不入库（防错误固化）。auto_train 的 run_round(replay=True) 保留此能力。
- **判据对齐理论**：教材采集=外部监督（标注验证）；经验回放=内部监督（实践验证）——两层知识来源，同一持久层。

### L1 训练执行——自动化循环

- 训练轮：24 题/科 × 8 科，查证学习（LearnerLoop 复用），答对回放
- 评估轮：12 题/科 × 8 科（**与训练题不重叠**，rng 抽样分离），测知识泛化
- 每科独立 body（测单科能力，不跨科污染）

### L2 质量反馈——看板与收敛

- 每轮输出：评估分数（总分+分科）、资料库规模、覆盖率、自主学习率、混叠数
- 收敛判定：连续 2 轮评估分数提升 < 1 个百分点 → 停止训练
- 收敛后报告未掌握题（能力边界清单）

## 四、防污染纪律（诚实性保障）

1. **只入答对的**——判定正确（extract_answer 命中 ground truth）= 实践考验通过
2. **训练/评估分源**——评估题不参与训练回放，无"背答案"作弊
3. **答案用标注**——入库的是 choices[ans]（数据集 ground truth），不是模型自答文本
4. **每科独立文件**——资料库按学科组织，不跨科混写

## 七、实验结果（2026-08-25 首轮验证）

### 配置对照

| 配置 | 第1轮评估 | 第2轮 | 第3轮 | 说明 |
|---|---|---|---|---|
| top3 无封顶 | **26.0%**（25/96） | 21.9% | 21.9% | 教材 192 条/轮 |
| top1 + 封顶48 | 21.9%（21/96） | 20.8% | 20.8% | top1 信息量不足, 封顶无效 |
| 单科 global_facts | **83.3%**（10/12） | — | — | 事实型知识教材泛化极佳 |

### 关键发现

1. **教材泛化 > 背题记忆**：global_facts 教材泛化 83%（12 个未见题）vs learner_loop 背题 67%——训练计划的"学习能力"指标超过"记忆"指标
2. **知识-区分度矛盾**：教材扩充 → 同科相似条目增多 → 检索混叠加剧 → 评估分数回落（26%→21.9%）。这是**检索式架构的根本张力**（知识量 vs 检索精确度），不是训练计划的缺陷——词汇一致性双条件闸已缓解但未根除
3. **分科差异**：事实型科（global_facts 83%）教材有效；推理/概念型科（数学/CS/经济 8-25%）检索架构本质限制（需要推理，非检索）
4. **环境修复**：HF 离线模式（mini_encoder）——断网下 transformers import 卡死修复，训练从卡死到 20s/轮

### 诚实结论

- 训练管道（教材采集→评估→收敛）建成且自动运行 ✅
- 事实型知识泛化显著（83%）✅
- 推理型科需**语义分层/同构检测/生成式**（远期架构方向）——教材越多混叠越重的矛盾是下一步主攻点
- 资料库从 171 → 391 条（训练成果持久化保留）

## 八、LeCun 批评的工程兑现（2026-08-25）

按杨立昆批评（相似≠因果 / 训练数据库≠训练模型 / 表征为预测而非相似）做的家用电脑可行改进：

### 改进 1：分离存储（实体分离的存储级实现）

| 改动 | 旧 | 新 | 依据 |
|---|---|---|---|
| 覆盖阈值 | 0.95（高相似即覆盖） | **0.98**（几乎相同才覆盖） | 旧阈值把"高相似但不同答案"抹掉（东京被上海覆盖） |
| margin 决策 | 一律要求 margin≥0.15 | **强命中（top1≥0.97）信任直接答；弱命中才要求 margin** | 分离存储后 0.95-0.98 相似对 margin 天然<0.05，一律要求会把已学知识全拒 |
| 词汇闸 | 所有命中都检查 | **短答案（<2 实义词，数字/专名）跳过词汇闸** | "13%"类选项答案无法词汇验证，闸误杀导致全 miss |
| 混叠检测 | — | `conflicts` 统计（诊断指标） | 计数高相似+答案不同知识对，供检索压力监测 |

**验证**：高相似对（cos 0.96）独立存储各自可答、模糊变体诚实弃权、无关 miss；查证模式 **3 轮稳定 25.0%**（改进前 26→21.9→21.9 的"教材越多越差"被消除——知识-区分度矛盾缓解）。

### 改进 2：内化评估（实证"训练数据库≠训练模型"）

- **内化模式**（`--internalize`）：教材（问题→正确选项）learn_response 进模型，评估不查证（benchmark_mode 禁探索）——测模型结构内能力
- **结果：1.0%**（1/96）vs 查证模式 25.0% / 单科 83%
- **实证价值**：教材内化进模型后泛化 ≈ 0——**之前的分数提升全部来自资料库（环境）与查证动作（grep），不是模型结构变化**。杨立昆批评成立：这个系统在"训练数据库"，不在"训练模型"。
- **诚实的指标**：内化评估剥离环境增益，暴露模型真实记忆泛化水平——后续一切"模型变强"的宣称应以它为基准。

### 结论

改进 1 缓解了检索架构的知识-区分度矛盾（机制级有效）；改进 2 给出了诚实的模型能力基线（1%），指向真正的下一步：**让 responder 学"完整事实结构"（实体+关系）而非短答案配对**——这是 LeCun"预测式表征"的最小可行工程化。

### 可微记忆进权重：性能可行性（LAM 原型验证，2026-08-25）

**问题**：LeCun 处方"记忆进权重"（可微记忆）在家用电脑是否可行？**结论：可行，且性能更优——但路径不是梯度训练网络，而是线性联想记忆（LAM）**。

| 维度 | 余弦检索（现状） | 线性联想记忆 W（可微记忆） |
|---|---|---|
| 原理 | 存储-检索（几何距离） | **线性映射 a_pred = W·z**（功能关系） |
| 学习 | 判定反馈 + 软校准 | **delta 规则闭式更新**（无反向传播） |
| 复杂度 | O(n) 随条目线性增长 | **O(1) 矩阵乘（3.2 µs/次实测）** |
| 内存 | 条目存储（随 n 增长） | **固定 96 KB（384×64 float32）** |
| 混叠 | 高相似对互相干扰（margin 弃权） | **学特征组合 → 混叠对可区分** |
| 模糊变体 | margin 不足 → 弃权（miss） | **线性泛化 → 仍给正确方向** |

**原型数据**（`_lam_proto.py`，384d 情境 → 64d 答案）：
- 东京/上海混叠对（相似度 0.80）：W 正确区分（rainy 0.77 / sunny 0.81）✅
- 模糊变体（余弦 margin 0.188 弃权区）：W 仍给正确方向（rainy 0.73 vs sunny 0.21）✅
- 无关查询：低置信（<0.05）可被校准拒绝 ✅
- 性能：**3.2 µs/次，96 KB**，100k 次预测 322ms

**接入路径**（与现有架构无缝）：
1. W 的监督信号 = 现有判定反馈流（report_outcome）——每条判定正确 → W 向答案方向更新
2. 答案向量化：MiniLM 编码答案文本（现有编码器即可）
3. 双层决策：W 预测答案 → 与检索条目答案比对 → 一致高置信直接答；不一致 → 检索 margin 决定（诚实弃权）
4. 效果预期：内化评估（现 1%）有望显著提升——W 学功能关系，不靠几何相似

**诚实边界**：线性 W 只能学线性可分关系（非线性实体交互需核方法/多层，家用电脑成本上升）；需答案编码器；训练需判定反馈数据流。这是"记忆进权重"的**轻量工程化**，非完整深度可微记忆——但在当前架构上是性能与能力的双优解。

### 表征空间推理加工：权重间泛化（脑内思维的工程前提，2026-08-25 实测）

**问题**：能否在高维表征空间做"推理加工"——权重之间泛化，不接触外部，用已有记忆巩固或发现新知识（类人脑内思维）？

**数学前提**（已验证于 MiniLM 384d 句向量空间，`_repr_reason.py`）：

| 推理形式 | 运算 | 实测 |
|---|---|---|
| **关系转移/类比** | v(B+关系) ≈ v(B) + [v(A+关系) − v(A)] | ✅ 天气 +0.095 / sunny +0.078 / language +0.030（vs 基线） |
| **词级类比**（word2vec 式） | v(A) − v(B) + v(C) ≈ v(D) | ❌ 句向量空间不成立（关系在模板对间，不在实体差间） |
| **巩固重放** | 无外部输入，内部重复更新 | ✅ 10 次重放 → 3 条沉淀 core（睡眠重放的检索式等价） |
| **权重复合**（传递推理） | W₂·W₁·z | 数学上可行（矩阵复合），未实测 |

**关键结论**：
1. **能**——表征空间推理成立，关系位移可转移（同模板不同实体的可组合性实证，正是 LeCun"实体/关系分离"的数学形式）
2. **关系在模板对之间，不在实体差之间**——词级类比（king−man+woman）在句向量空间失效，但"模板对位移"（东京雨天−东京 ≈ 上海雨天−上海）有效——架构启示：**显式分离"模板层"（共享关系）与"实体层"（分开槽位）**
3. **脑内推理产生的是"假设"，不是知识**——候选新知识必须回到实践（外部判定/检索验证）才能沉淀——这正是受阻-通过判据的哲学位置：**表征空间推理（假设生成）× 受阻-通过（实践验证）= 完整思维→知识循环**（辩证唯物主义实践论的技术实现）

**落地路径**（家用电脑）：双通道 LAM（W_fact 事实映射 + W_rel 关系位移）+ 空闲期思维循环（重放/关系转移产生候选 → 受阻-通过验证 → 沉淀）。成本：矩阵乘/向量加减，微秒级。

### LAM 落地实证与适用边界（2026-08-25）

**实现**（respond_learner）：W(情境 1152d → 答案向量 384d) delta 规则在线更新；learn 时 ground truth 监督 + report_outcome 判定反馈强化；respond 检索 miss 与 margin 拒绝分支接 W 兜底（双条件：top1 cos≥0.55 且 top1-top2≥0.15，防无关查询误答）；save/load 持久化。96KB 权重，O(1) 预测。

**实证结果**：

| 场景 | 结果 | 结论 |
|---|---|---|
| 关系型（同模板不同实体：东京雨天→rainy 变体） | ✅ 4/4 | W 可泛化关系（线性位移转移） |
| 无关查询 | ✅ 拒绝 | margin 条件防误答 |
| **事实型（MMLU 教材内化评估）** | ❌ 1.0% | W 对独立事实无效 |
| 机制回归 | ✅ 全过 | 无破坏 |

**适用边界的本质结论**（重要）：
- **关系型知识**（东京/上海共享"天气"模板，答案由关系推导）→ W 可泛化——权重适合承载**可组合的关系结构**
- **事实型知识**（adults 40%、children 38% 独立事实，答案与实体无共享模式）→ W 无效——**没有可学的关系，只有一堆独立事实**，线性映射无法外推
- 同题变体（教材 13% vs 评估 40%，问题几乎相同答案不同）→ 余弦/词汇闸/W 全部失效——**终极同构混叠**，只有"精确记住该事实"或"外部查证"能解

**架构含义**：记忆进权重的边界 = **关系可组合性**。事实记忆要么外部检索（查证模式 25%），要么参数化大模型（LLM，非本架构）。这回答了"可微记忆能否优化性能实现"——**能，但只在关系型任务域**；事实型任务域权重记忆不是解。

### 分工模型：事实缓存 × 关系权重 × LLM 翻译器（2026-08-25）

**关键重定位**（来自架构讨论）：
1. **事实记忆 = 缓存，不是泛化器**——评估用"重复命中率"而非"未见题泛化率"。MMLU 一次性题集测不出缓存价值（1% 是评估错位非失败）；真实世界重复任务中，事实缓存命中省查证（省时间/IO/避开查证噪声）。
2. **沉淀判据合题**：受阻-通过（质量）× 重复需要（频率）= 长期记忆判据——质量防错误固化（实验 B 教训），频率保证缓存只存用得上的（用户补充的维度）。
3. **LLM = 符号翻译器**（语言 ↔ 意图 ↔ 符号），不承担事实记忆——事实必须来自认知层（缓存/查证），LLM 只表达（防幻觉、可追溯，对齐命题 5 可证伪性）。与 LeCun 语言观一致：语言是低带宽输出通道。

**三层分工**：

| 层 | 组件 | 职责 |
|---|---|---|
| L0 符号层 | LLM 翻译器 | 语言↔意图↔符号（表达，不产生事实） |
| L1 认知层 | fast 检索 + W 权重 + core 缓存 | 短期记忆 / 关系推理 / 事实长期记忆 |
| L2 事实缓存 | 查证 → 受阻-通过×重复需要 → 沉淀 | 重复场景命中，省查证 |

**架构形态**：`问题 → [LLM 翻译] → JEPA 认知(检索/W/缓存) → 事实候选 → [LLM 翻译] → 回答`（RAG 的认知架构版）。

### 思考判断遗忘：长期缓存的主动修正（2026-08-25）

**问题**：core 沉淀后基本永久，错误缓存侥幸达标即固化（实验 B 病理）。用户主张：JEPA 在实际工作中"思考判断"后选择性遗忘。

**机械遗忘（已有，条件反射）**：受阻-通过（单次判定）/ 负样本 / falsified / cap 淘汰——只管"不沉淀"与 fast 层，**管不了 core 的固化**。

**思考判断遗忘（要补，多证据综合）**——遗忘评分，运行时（每次判定/learn 后）持续计算：

```
遗忘评分 = 冲突证据(与新验证知识矛盾, conflicts 检测)
         + 校准证据(所在桶 P(对) 崩)
         + 时间证据(长期未命中)
         + 冗余证据(与多条目重复)
超阈值 → 降级/归档
```

三个关键场景：①**污染撤销**：core 命中答错 → 巩固分跌破 → 降回 fast（再错淘汰）——core 从"永久"变"持续受审"；②**过时淘汰**：新知识验证通过且与旧缓存冲突 → **冲突评审**（新旧验证历史权衡，多者留）——这是"思考"而非简单覆盖；③**冗余合并**：相似且答案一致 → 合并模板。

**关键设计**：降级 = 移入"衰退区"（归档非删除，检索权重降低），可被未来证据恢复——**遗忘是暂时不可访问，不是删除**（对应"忘记≠删除"，可追溯可恢复）。

**哲学**：机械遗忘=单次实践判定（条件反射）；思考遗忘=实践史累积综合（多次证据→结论）——遗忘判断不该由单次实践决定（可能误判），应由实践史的辩证综合决定。冲突评审权衡新旧验证史，而非新覆盖旧。

**与病理对照**：错误固化（该忘不忘）→ 巩固分+降级；判别信息丢失（不该忘的忘了）→ 归档可恢复；认知僵化 → 冲突评审。**记忆不是终点，是过程——长期记忆=持续接受实践考验的活跃记忆。**

### 分层遗忘：fast × W × core（2026-08-25 收尾）

三层记忆的选择性遗忘机制设计（统一原理：**遗忘优先级 ∝ 判别价值 × 验证历史**）：

| 层 | 遗忘对象 | 本质 | 机制 | 时间尺度 |
|---|---|---|---|---|
| **fast**（短期检索） | 条目 | **过滤器** | 淘汰 = 质量分×时间加权（最低分×最旧先滚）；保护 = 高分/近期命中 | 即时（每轮流动） |
| **W**（权重记忆） | 权重方向 | **弹性体** | ①慢衰减 W*=(1-λ)（λ≈0.01）防过时固化；②验证强度 G 保护（判定正确 G+=|z|，更新步长按 1/G 缩放——高 G 方向受保护=EWC 对角线近似）；③错误抵消（判定错误→错误方向负向更新，撤销污染） | 慢（衰减 λ） |
| **core**（长期缓存） | 沉淀条目 | **审查者** | 巩固分+冲突评审+归档降级（上节） | 最慢但可逆 |

**fast 角色重定位**：从"纯容量池"升级为"**待沉淀池**"——答错-2 的条目不仅不沉淀，还优先被淘汰（当前只"不沉淀"，还能在 fast 赖很久）。

**W 的选择性本质**：不是全忘（灾难性遗忘）也不是不忘（过时固化）——**验证强度 G 决定每个方向的更新自由度**：被实践验证多的方向（高 G）坚守，次要方向自由更新。这是"实践决定哪些信念值得坚守"的权重级实现。

**哲学**：fast=量变（条目流动保新鲜）；W=质变（权重方向随实践史修正）；core=扬弃（沉淀再审）。**选择性遗忘=记忆的优先级管理，不是删除**。

### 矛盾处理协议（2026-08-25 已实现，认知升级）

**目标**：处理矛盾事实（同情境两答案）与矛盾关系（同情境两映射）。**核心原则（LeCun 修正贯穿）**：符号比较只是初筛，**实践（预测误差/验证史）是精确裁决**；无法裁决时**宽容并存**（可能是条件/时间差异），让实践继续检验。

**协议流程**：
```
learn 符号检测 (高相似情境+答案文本冲突 → 矛盾对记录)
  → report_outcome 实践裁决:
      双方正验证 & 正确率≥60% → complementary (条件/时间差异, 宽容并存)
      一方错误≥2 (实践强烈否决) → 该方判负 (resolved, 输方弃权)
      否则 → pending (宽容等待, 不弃权, 不冤枉未验证方)
  → respond 命中裁决输方 → 弃权 (last_block=contradiction → 触发查证闭环)
```

**五场景验证**（contradiction_check.py 全过）：互斥裁决（rainy 3对 vs sunny 2错 → sunny 输方弃权）/ 互补并存（冬夏都验证通过 → 双方可用）/ 宽容等待（单方验证 → 未验证方不被冤枉）/ 错误判负（cityP 2错 → 弃权触发查证）/ 冗余同义（子集 → 不构成矛盾）。

**LeCun 修正过程**（实现中被他的视角纠正的 4 处）：
1. 检测信号：符号比较（答案相似度）不可靠——反义词 rainy/sunny 词重叠高但语义互斥 → 检测只作初筛，分类/裁决交给实践
2. 验证死锁：pending 弃权会阻止双方累积验证 → 宽容并存（不弃权），谁开始错谁出局
3. 时序冤枉：单方先验证就裁决会判死未验证方 → 无错误时宽容等待
4. 文本冲突判定：共享词比例阈值漏检反义对 → 改为"双方都有独有实义词且共享<0.85"

**集成**：冲突评审从"learn 机械减 core 分"升级为矛盾协议（检测→实践裁决）；status 暴露矛盾统计（total/pending/resolved/abstain）；save/load 持久化；learner_loop 生态保持（83.3%）。**矛盾 = 高级受阻 = 需要更多实践**——JEPA 现在能"面对矛盾、追问矛盾、条件化矛盾"。

### 认知架构蓝图：三层记忆 × 遗忘三重作用（2026-08-25）

```
  短期记忆(检索机制)                 长期记忆(权重+表征运算)
  fast 层: 情境→条目                  W(线性联想): 功能映射
  显式/精确/易失/cap淘汰             隐式/可泛化/稳定/O(1)可运算
        │ 重复+判定反馈                       │
        ▼                                    ▼
  受阻-通过判据 ──沉淀(经重构)──→ core 层(长期记忆=模板+实体槽)
                                            │
                                    表征运算(关系转移/权重复合)
                                            ▼
                             候选新知识(假设) → 受阻-通过 → 沉淀
```

**两条知识路径**：①外部实践归纳（查证→判定→沉淀）；②内部表征运算（推理→假设→验证→沉淀）。共享同一道实践之门（受阻-通过判据）。

**遗忘三重作用**：
| 类型 | 位置 | 机制 | 作用 |
|---|---|---|---|
| 容量遗忘 | fast 层 | cap 淘汰 | 检索效率（运动层流动） |
| 纠错遗忘 | 沉淀层 | 答错-2 不沉淀 | 防错误固化（污染惩罚） |
| **重构遗忘** | fast→core | 抽象细节保留结构 | 可泛化的长期记忆（扬弃） |

**重构遗忘的根本矛盾与解法**：细节 = 判别信息（东京/上海差异，丢了就混叠）vs 细节 = 噪声（日期/措辞，留了只膨胀）。判别标准 = **实践检验**（丢了会答错的=判别信息要保留；从未影响判定的=噪声可遗忘）。信息论表述：**遗忘 = 按判别互信息选择性丢弃 = 最小描述长度（保留能重构全部判定行为的最小结构）**。

**工程化 = 模板化（扬弃的 Aufhebung）**：相似条目聚集 → 共享部分=模板（遗忘的细节）+ 差异部分=实体槽（保留的判别信息）；模板太抽象致混叠 → 受阻 → 模板分裂补回细节；够用 → 巩固。与实测一致（关系位移在模板对间成立）。

**与 LeCun 交锋**：灾难性遗忘是 bug（他，用正则化防）vs 选择性遗忘是 feature（我们）——真正的病理是"忘错了"（判别信息丢失=表征失真）与"记错了"（错误固化=认知僵化）；健康=只忘噪声不忘判别，由实践检验逐步调出。**长期记忆的本质不是记得多，是忘得对；遗忘是认知再生产（flux）的动力。**

## 九、风险与边界

- **同源风险**：训练轮答对的题再次出现（同 seed 同抽样）→ 直接命中 = 记忆巩固，非作弊（评估用不同题集排除此混淆）
- **资料库膨胀**：24 题/科 × 8 科 × 3 轮 ≈ 576 条新增，research_execute 的 grep 线性扫描仍可接受（每条 <200 字符）
- **检索退化风险**：入库条目与训练题高度相似 → 同构混叠可能增加 → 词汇一致性闸（双条件）继续兜底
- **诚实边界**：检索式架构的知识泛化上限 = 资料库覆盖 × 检索区分度。本计划解决前者，后者已由双条件闸缓解。超越此边界需语义分层/生成式（远期）。
