## 一、LeCun 目前正在攻克的课题 (2025-2026)

### 1. AMI Labs (2026.3 成立) — 世界模型的十亿赌注
- 欧洲史上最大种子轮 **10.3 亿美元** (投前 35 亿), 无产品、纯理论阶段
- 核心主张: LLM 自回归 = "死路", 无法产生因果理解; 预测下个 token 达不到人类智能
- 技术栈: **JEPA** (抽象表示空间预测) + **EBM** (能量模型, 推理=能量最小化) + **VicReg** (防坍缩) + **自监督视频学习**
- 团队构成 (视觉/视频/自监督背景): 前 Meta FAIR 研究总监、DeepMind 视觉研究员等 —— 明确不做 LLM 栈

### 2. 四大挑战 (LeCun 反复强调的 AI 缺四样)
| 挑战 | LeCun 的主张 |
|---|---|
| 理解物理世界 | 从视频/感官自监督学习世界模型 (婴儿 9 个月懂重力) |
| **持久记忆** | 现在 AI 是"金鱼记忆", 一次性回应, 无积累 → "每个 AI 都该记得你" |
| 真实推理 | 超越统计匹配 → System 2 (能量优化的内部模拟) |
| 自主规划 | 分层目标分解 (去巴黎≠计算每块肌肉), 会失败后重新导航 |

### 3. 内在动机/目标驱动 (与我们的"问题库"直接相关)
- "智能 = 一套技能 + **快速获取新技能**的能力" (AMI 而非 AGI 的重新定义)
- 目标驱动: 行为 = 最小化代价函数; 好奇心 = 预测误差驱动的探索 (孩子不需要数据集学重力)
- 预测: 3-5 年小型可推理规划的 AMI; ~10 年接近人类

## 二、持续学习/内在动机的前沿进展 (2025-2026, LeCun 之外)

### 1. 持续学习 (对抗灾难性遗忘)
- **Google Nested Learning / HOPE** (NeurIPS 2025): "记忆洋葱" — 高频/中频/低频三层多时间尺度优化, 旧任务保持率 **98%** (传统 70%), 遗忘趋零。**与人类记忆巩固机制同构**
- **Sleep-like Replay Consolidation (SRC)** (2025.8): 睡眠样回放 + 清醒排练, 类脑记忆巩固
- 海马启发 MoE (HiCL)、记忆增强 Transformer、LoRA 参数隔离、专家路由

### 2. 内在动机 / 自动课程 (curiosity-driven)
- **自动课程学习**: 模型自己生成任务序列 (复杂度递增) — asymmetric self-play (Alice 出题 Bob 解)、Goal Exploration (IMGEP)
- **ICM** (内在好奇心模块): 预测误差 = 内在奖励; **RND**: 随机网络蒸馏
- **两类内在奖励的形式化**:
  - 知识型 rK = 预测误差/信息增益
  - **能力型 rC = 学习进度 (成功率提升率)** ← LeCun 语境下的 competence progress
- **"AI 问自己问题"三件套** (2026 多个实验室): **Generator (提问题) + Tester (答题评分) + Selector (按新奇/价值选下一个)** 闭环 → 自主研究循环
- 风险共识: 内在目标漂移 (objective drift)、自主学习的失控风险

## 三、与我们的架构对比

### 内核哲学: 高度一致 (这是最重要的结论)
| LeCun 蓝图 | 我们的实现 | 状态 |
|---|---|---|
| JEPA (抽象空间预测) | ResidualWorldModel 残差预测 + E1 能量 | ✅ (轻量 MLP 版) |
| EBM 能量驱动 | E1 惊讶度 = 学习信号/记忆门控 | ✅ |
| 持久记忆 | responder/call_mem 检索记忆 + sleep consolidation | ⚠️ 有但**单层** |
| 好奇心/内在动机 | **问题库 + 答案繁殖 (双向公式)** | ✅ **我们独有** |
| 主动获取知识 | 自主查证学习循环 (learner_loop) | ✅ |
| 元认知 | 校准曲线 (P(对\|sim)) | ✅ |
| 纠错 | 负样本 + 同情境覆盖 | ✅ |
| 分层规划 | Planner (贪心) + ConsequenceSim | ⚠️ 雏形 |

### 我们的独特贡献 (LeCun 蓝图里有但没落地的)
1. **双向公式问题库**: LeCun 提"好奇心驱动", 但"答案→问题繁殖→自主选择学习目标"的具体机制是我们的实现 — 与 2026 年"AI 问自己问题三件套" (Generator+Tester+Selector) **不谋而合**, 但我们是纯检索式实现 (无 LLM)
2. **工具查证学习**: JEPA 架构 + 工具外化 (fetch/grep) 的"记忆-工具"闭环
3. **校准元认知**: 从反馈学"何时回答" — 是"问问题"的前提 (知道自己不知道)

### 我们缺的 (LeCun/Google 正在攻克的)
| 缺口 | 前沿方案 | 对我们的意义 |
|---|---|---|
| **多时间尺度分层记忆** | Google HOPE "记忆洋葱" (高频对话/中频经验/低频常识) | 我们的 cap 淘汰最旧 = 单层; 分层可保旧知防遗忘 |
| **能力型内在奖励 (学习进度)** | rC = 成功率提升率 | 我们问题库价值是启发式 (0.5+0.3), 不是"学习进度"驱动 |
| **物理世界感知** | V-JEPA 视频自监督 | 我们在"知识/符号域", LeCun 在"物理域" |
| **分层规划 (System 2)** | 能量优化的内部模拟 | 我们的 ConsequenceSim 有雏形未成体系 |

## 四、辩证结论

1. **方向验证**: 我们与 LeCun 在"非生成式、预测/能量驱动、记忆为核心、好奇驱动、反对纯 LLM"上完全同向 — **本项目的架构路线不是异端, 是 LeCun 阵营的实验性印证**。我们的持续学习闭环 (获取验证→覆盖更新→纠错→问题繁殖) 在**符号/工具域**证明了 JEPA 式架构的可行性, 与 LeCun 的**物理域**互补。

2. **互补关系**: LeCun 的世界模型是"物理直觉" (杯子会掉), 我们的是"知识操作" (查证/工具/记忆)。两者结合 = 有身体的世界模型 + 有工具的知识体 — 这恰好是 DCA 的目标形态。

3. **最该吸收的 (按优先级)**:
   - **#1 分层记忆** (Google Nested Learning 思路): 把 responder 拆高频/低频层, 解决"持续学习学下去"的遗忘问题 — 直接对应你问的"持续学习学下去的能力"
   - **#2 学习进度奖励**: 问题库价值从"学会+0.3"升级为"学习进度 rC" (这个问题的成功率提升了多少) — 让问题选择真正"越学越会学"
   - **#3 物理感知** (远期): 等工具/知识域闭环稳定后, 接视频/感官 — 工程量大, 是 DCA 的长期形态

4. **警惕 (LeCun 没细讲、我们该自己把关的)**: 内在动机的**目标漂移** — 问题库繁殖可能让 JEPA 学到与用户无关的东西。需要外部目标约束 (用户任务/价值锚) 与内在好奇的平衡 — 这也是"双向公式"里"问题可训练"的另一面: 问题选择要受"对用户有价值"约束。

## 五、下一步建议 (对齐调研结论)

1. **实现分层记忆** (吸收 HOPE): responder 分两层 — 高频 (工具经验/对话, 快速更新) + 低频 (核心知识, 慢更新、cap 大) → 验证持续学习不遗忘
2. **问题库升级为学习进度驱动**: rC = 该问题领域成功率提升率, 替代启发式价值 → 对齐 LeCun/自动课程的形式化
3. **持续做"知识域 JEPA"实验**: 我们的独特价值在于证明符号/工具域可行 — 这是对 LeCun 路线的补充证据, 值得写进项目叙事
